## 使用方法

### 方式 A【图形界面版 - 推荐】
1. 下载解压后，双击运行 `1-图形版-双击启动.exe`；
2. 工具会自动识别本地游戏安装路径；
3. 阅读并勾选风险说明；
4. 点击「一键应用【简体中文】」或「一键应用【繁体中文】」；
5. 提示安装成功后，直接从 Steam 启动游戏即可。

### 方式 B【窗口版】
- 双击运行 `2-窗口版-安装简体中文.bat` 安装简体中文
- 双击运行 `2-窗口版-安装繁体中文.bat` 安装繁体中文（会覆盖简体）
- 双击运行 `3-窗口版-还原官方原版.bat` 还原官方英文
- 双击运行 `4-出问题点这个-生成诊断.bat` 生成诊断报告

## 一键还原

任何时候想恢复官方英文：
打开图形界面点击「一键还原官方英文」，或双击运行 `3-窗口版-还原官方原版.bat`。

还原后请勿再手动改动游戏目录；若还原异常，可在 Steam 中对游戏执行「验证文件完整性」。
