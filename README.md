# ROB RUN Steam 简繁一键汉化补丁

**下载**：[最新版本](../../releases/latest)　**使用说明**：见压缩包内 `0-使用说明（先看这里）.txt`

---

## 功能特性

- **支持平台**：Steam 版《ROB RUN》
- **语言支持**：一键切换【简体中文】与【繁体中文（台灣慣用詞）】
- **文本覆盖**：完整覆盖游戏内界面、商城外观、载具、武器、配件、任务、纹身等 4,829 条官方文本
- **纯净还原**：支持随时一键完全还原回官方纯净英文，不影响后续游戏更新

---

## 使用方法

### 方式 A【图形界面版 - 推荐】
1. 下载解压后，双击运行 `1-图形版-双击启动.exe`；
2. 工具会自动识别本地游戏安装路径；
3. 阅读并勾选风险说明；
4. 点击「一键应用【简体中文】」或「一键应用【繁体中文】」；
5. 提示安装成功后，直接从 Steam 启动游戏即可。

### 方式 B【窗口版】
- 双击运行 `2-窗口版-安装简体中文.bat` 安装简体中文
- 双击运行 `2-窗口版-安装繁体中文.bat` 安装繁体中文
- 双击运行 `3-窗口版-还原官方原版.bat` 还原官方英文

---

## 一键还原

任何时候想恢复官方英文：  
打开图形界面点击「一键还原官方英文」（红色按钮无需勾选协议，随时可用），或双击运行 `3-窗口版-还原官方原版.bat`。
