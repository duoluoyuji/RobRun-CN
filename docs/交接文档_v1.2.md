## 三、日常维护流程（游戏更新后）

1. **导出新文本**：从游戏目录重新导出 `strings_en.csv`，与 `01_源文本` 里的旧版做 ID diff，找出新增/改动条目。
2. **补译**：把新增条目写进 `_v2\data\已译补丁.csv` 与 `已译补丁_繁體.csv`（两边都要）。
3. **查缺字**：若新译文引入了字库没有的汉字，先跑 `patch_perfect_fonts_tw.py`（繁体会自动从词典统计缺字；简体参照同一写法）。**参数不要改**（字号/边距取自字体资产自身，4x 超采样，0.88 横向比例）。
4. **打包**：
   `python build_pack.py <译文CSV> <输出目录> <官方bundle目录> <字库inbuild> <locales bundle>`
   - 官方 bundle 目录：干净游戏 `ROB RUN_Data\StreamingAssets\aa\StandaloneWindows64` 的副本（`_v2\assets\official-2026.11.17`）
   - 字库：`_v2\out\fonts\zh`（或 `zh-TW`）里的 `inbuild_assets_all.bundle`
5. **过闸门**：`python check_release.py <词典CSV> <官方表CSV> <字库inbuild> <包目录>`
   - 六项必须全 PASS：词条数=官方、参数不越界、plural 段数一致、富文本标签不缺、无批注残留、字库 0 缺字
6. **组包**：`_v2\tools\build_suite_v2.ps1`（调 `csc.exe` 编译 EXE、组装目录、写清单、压缩）
7. **自测**：还原 → 装简 → 装繁 → 还原，四个动作都要验证文件哈希与游戏内文本。

## 四、安装/还原机制（使用者视角）

- 工具把 8 个汉化资源包写入游戏 `aa\StandaloneWindows64`，命名为 `*_zh0.bundle`；
- 同时把 `catalog.bin` 里的 8 个引用指向 `*_zh0.bundle`，并同步运行时缓存；
- 还原时删除 8 个 `*_zh0.bundle`、从 `catalog.bin.bak` 恢复官方 catalog、清理缓存；
- 官方文件始终保持原样，因此可随时一键还原。
